# Twitter-Like Functionality

A Django-based mini project to mimic Twitter’s 'like' feature for posts.

---

## 🚀 Features
- Click to like/unlike posts
- Real-time like count updates
- User authentication (optional)
- delete post
- create post
- update post

---

## 🛠️ Tech Stack
- Backend: Django
- Database: SQLite (default)
- Templates: Django Templates / JavaScript

---
